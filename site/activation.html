Активация лицензии

Активация выполняется на компьютере без подключения к интернету — никаких аккаунтов и VPN не требуется (DoD §5.8: работает ≥ 30 дней и дольше без сети).

Порядок действий

  1. Установите smetana: Windows — SmetaNA-<версия>-win-x64.exe; Linux — sudo apt install ./smetana_<версия>_amd64.deb.
  2. Запустите приложение: меню Справка → Активация (в режиме пробного периода — окно активации при запуске).
  3. Вставьте лицензионный ключ из письма о покупке и нажмите «Активировать».
  4. Готово: лицензия привязывается к этому компьютеру, интернет не нужен.

Перенос на другой компьютер

  1. На старом компьютере: Справка → Активация → Деактивировать — сохраните файл-чек деактивации.
  2. На новом: активируйте тот же ключ (количество переносов ограничено тарифом).

Если что-то не получается

  • Проверьте, что ключ скопирован целиком (включая дефисы).
  • Пробный период 14 дней работает без ключа.
  • Восстановление ключа — через поддержку: support@smetana.example.ru, укажите email покупки.
При активации приложение запоминает только идентификатор ключа и необратимый отпечаток компьютера (хеш конфигурации) — никакие ваши модели и файлы не передаются и не покидают компьютер. Подробности: политика приватности.

Нет лицензии? Купить smetana или начните с пробного периода в приложении.
