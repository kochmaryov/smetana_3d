SmetaNA · дизайн интерфейса · вариант D

Минимальная строка закреплённых инструментов + палитра команд

На виду — только 5–7 инструментов, закреплённых пользователем, и поле поиска команд (Ctrl+K) с иконочной выдачей, сгруппированной по категориям. Всё остальное — через палитру или правый клик по сцене («Недавние» и «Все инструменты»). Настройка = закрепить/открепить + страница настроек «Инструменты».

Оценка варианта

Плюсы

  • Максимум места под 3D-сцену; строка инструментов — одна тонкая полоса.
  • Палитра команд даёт быстрый доступ к любому инструменту по имени — удобно профи.
  • Минимум настраиваемых сущностей: закрепил/открепил — и готово.

Минусы

  • Новичок не видит набора инструментов — прямой риск для сценария S1 («15 минут без обучения»).
  • «Группировка инструментов» существует только внутри палитры — требование выполнено наполовину.
  • Зависимость от памяти горячих клавиш и навыка поиска; у учителя дольше объяснять «где кнопка».

Реализация и адаптивность

  • Объём: палитра команд — средний; контекстное/радиальное меню по сцене — крупный отдельный контрол.
  • Идеально для узких экранов и 768 px; на 1920 px тулбар выглядит «пустым».
  • Осмыслен как развитие A/B/C (палитра команд есть в плане M10 v1.x), но не как единственная панель.
