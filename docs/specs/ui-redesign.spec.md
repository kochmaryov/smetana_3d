## 1. Цель

Устранить три системных дефекта текущего UI:

1. **Иррациональное распределение рабочего пространства** — пустоты (Welcome с карточками в пустом центре, статус-строка с провалом), плавающие оверлеи внутри вьюпорта (панель режимов до 600 px, HUD, ряд из 8 кнопок видов).
2. **«Дешёвое» оформление** — дефолтный FluentTheme: плоские панели без глубины, тонкие рамки, мелкие иконки, отсутствие визуальной иерархии.
3. **«Расползание» областей инструментов** — дубль «меню + тулбар», попапы панелей поверх сцены 340×520, широкая строка VCB+статус+подсказка — всё это отнимает основное рабочее пространство.

**Решение (концепт, утверждён 2026-11-01):** гибрид «Docked Studio (A) + Command Canvas (C) + перемещаемые группы» в единой тёмной CAD-теме.

**Критерии успеха продукта:**

1. Сцена занимает ≥ 70% окна на 1280×800; в покое ни один элемент не лежит поверх модели.
2. Все инструменты доступны ≤ 2 действий двумя путями: явным (палитра) и быстрым (Ctrl+K / панель у курсора / хотбокс).
3. Любая группа инструментов перемещается (по группам) в любое место экрана или прикрепляется к любому краю; раскладка переживает перезапуск.
4. Ни один экран (редактор, Welcome, диалоги) не выпадает из визуальной системы; ошибки и пустые состояния оформлены наравне с рабочими.

## 2. Область действия

### Входит

- **Главный экран:** единая шапка (меню + быстрые команды + документ + режимы вьюпорта + Ctrl+K + тема/язык), левая палитра инструментов, правый док с вкладками, статус-строка с VCB (три состояния), вкладки проектов
- **Перемещаемые группы инструментов (tear-off):** отрыв группы за «⠿», плавающее размещение в любом месте экрана, прикрепление к краям с подсветкой зон, закрытие, сохранение раскладки
- **Командный слой:** палитра Ctrl+K (поиск по реестру инструментов и команд), контекстная мини-панель у курсора, хотбокс по пробелу (радиальное меню)
- **Панели правого дока:** Свойства, История, Горячие клавиши, Зона печати, Урок — в единой теме, с оформленными пустыми состояниями и ошибками (например, выход модели за зону печати)
- **Строка VCB:** три состояния — «Готово» / ввод значения (акцентный промпт) / ошибка (красное значение + рамка + текст)
- **Виджеты вьюпорта:** HUD одним чипом; кнопки стандартных видов — компактный сегмент-контрол; подсказка камеры — в статус-строку
- **Вкладки проектов:** типовые editor-табы с акцентной строкой активной
- **Welcome:** асимметричный hero (ценность + CTA + единицы) + колонка «недавние файлы / продолжить урок» вместо карточек в пустоте
- **Диалоги:** «Настройка панели инструментов» (с учётом плавающих групп), «Новая группа», «Ошибка», «Лицензия» — в единой теме
- **Визуальная система:** тёмная CAD-тема как базовая (слоистые поверхности, акцент `#E8A33D`, радиусы 5/8 px, тени, шкала типографики), светлая — производная от токенов
- **Адаптивность:** 768–1920 px и zoom 90–125% — док сворачивается, палитра деградирует в рейл (текущая логика), командный слой не зависит от ширины

### Не входит (non-goals)

- Изменение рендеринга/OpenGL-вьюпорта, логики инструментов, геометрического ядра, форматов и экспорта
- Новые зависимости/библиотеки (только Avalonia 12 + .NET 10)
- Отказ от палитры в пользу Ctrl+K как единственного пути (палитра остаётся базовым каналом для новичков)
- Пользовательские иконки (импорт SVG) — v1.x
- macOS/iPad/веб-версии; маркетплейс расширений
- Переработка системы лицензирования/платежей (не применимо — внутренний продукт)

## 4. Решения

| Область | Решение | Обоснование |
|---|---|---|
| Общая композиция | **Гибрид A+C:** каркас «док-студии» (A) + командный слой (C) по требованию + перемещаемые группы | A даёт обучаемость (всё видно — S1), C даёт скорость после 1–2 уроков; гибрид закрывает оба сценария; чистый C отклонён (риск для новичков) |
| Шапка | Одна строка 40 px: меню + быстрые команды + документ + режимы вьюпорта + Ctrl+K + тема/язык | Убирает дубль «меню + тулбар»; режимы из 600-px оверлея — в шапку: сцена не перекрывается, провалов в композиции нет |
| Палитра инструментов | Левая палитра (компактная, ~76 px, 2 колонки), группы с ручкой «⠿» | Сохраняет «все инструменты видны» (S1, tool-palette T1); ручка — точка входа tear-off |
| Перемещаемые группы | **Tear-off:** группа — UserControl с заголовком-«⠿»; плавающий режим — Popup/Window поверх сцены (по выбору пользователя); докинг — зоны прикрепления по краям с подсветкой; позиции/закрепление — в JSON-настройках (версия схемы) | Требование заказчика; привычно SketchUp/Fusion («floating toolbars»); хранение — тот же механизм, что у раскладки палитры (T8 tool-palette) |
| Правый док | Dock с вкладками вместо попапов `RightRailControl`; содержимое — существующие `PropertiesPanel`, `HistoryPanel`, `ShortcutPanel`, `PrintVolumePanel`, `TutorialPanel` | Панели расширяют сетку, не перекрывают сцену (no-overlay); свойства/история видны постоянно — новичок ничего не ищет |
| Командный слой | Ctrl+K — ListBox-фильтр поверх `ToolGroupRegistry` + команды меню; панель у курсора — Popup с контекстными действиями по выделению; хотбокс (пробел) — радиальное меню | Два пути к инструментам (T4); слой появляется только по требованию, в покое сцену ничего не перекрывает; исследование SketchUp подтверждает слой поиска как стандарт ниши |
| HUD и оверлеи | HUD одним чипом; стандартные виды — сегмент-контрол внизу вьюпорта; подсказка камеры — в статус-строке | Прямое устранение «расползания» панелей по сцене (жалоба №3) |
| Строка VCB/статуса | Одна строка 30 px: VCB (три состояния) + статус + подсказки жестов/камеры + статистика справа | Убирает провал в строке (жалоба №1); ошибка — в контексте ввода, красным |
| Вкладки проектов | Типовые editor-табы в шапке (текущий `TabControl`, новое оформление) | Место в композиции уже предусмотрено; сравнение деталей — частый сценарий студентов |
| Welcome | Асимметричный split «hero ↔ список»: ценность + CTA + единицы слева, недавние/урок справа | Функциональное заполнение вместо декоративной пустоты (жалоба №1); новичок стартует ≤ 30 секунд |
| Диалоги | Плотные карточки, footer-кнопки, единая тема; «Настройка панели» — мастер «дерево ↔ панель» с пометками плавающих групп | Единая система (жалоба №2); сохраняет T3 tool-palette (drag&drop, свои группы) |
| Визуальная система | Тёмная тема как базовая (акцент `#E8A33D`, поверхности `#171B21`/`#1E242B`/`#262D36`, радиусы 5/8, тени, шкала шрифтов); светлая — производная через токены (`DynamicResource`) | «Дороговизна» за счёт глубины и типографики, а не градиентов; токенизация — обязательное условие поддержки обеих тем |
| Адаптивность | Док сворачивается ≤ 960 px, палитра → рейл ≤ 768 px (текущий `PaletteLayoutMode`); слой C не зависит от ширины | Сохраняет DoD адаптивности tool-palette без новой логики |
| Настройки | Раскладка доков, позиции и прикрепление плавающих групп — в JSON рядом с `EditorOptions`, со схемой-версией и миграцией | Переживает обновления версий (T8 tool-palette); отсутствие дублей — дефолты генерируются из `ToolGroupRegistry` |

### Альтернативы «в запас»

| Вариант | Идея | Почему не взяли | Когда берём |
|---|---|---|---|
| A. Docked Studio | Всё доковано, вкладки справа, максимум постоянной видимости | Нет быстрого слоя; палитра всегда занимает место | Если скорость навигации окажется некритичной |
| B. Adaptive Trays | Рейлы + выдвижные лотки, автоскрытие, максимум сцены «в покое» | Скрытые лотки = лишнее действие для новичков (S1) | Если приоритет «сцена в покое» обгонит обучаемость |
| C. Command Canvas | Хотбокс + Ctrl+K как единственный канал, минимум хромировки | Риск для школьников без опыта (критерий S1 «15 минут») | Эволюция для продвинутых; элементы уже взяты в гибрид |

## 5. DoD (критерии готовности)

1. **Композиция:** одна шапка; дублей команд нет; на 1280×800 сцена ≥ 70% окна; в покое (без открытых лотов/слоя C) ни один элемент не лежит поверх модели.
2. **Перемещаемые группы:** любая группа отрывается за «⠿», плавает в любом месте, прикрепляется к любому краю с подсветкой зоны, закрывается; раскладка переживает перезапуск и обновление схемы.
3. **Командный слой:** Ctrl+K находит и запускает любой из 24 инструментов ≤ 2 действий; панель у курсора показывает контекстные действия; хотбокс (пробел) открывается/закрывается без потери инструмента.
4. **Док:** все 5 панелей работают как вкладки; пустые состояния и ошибки (в т.ч. выход за зону печати) оформлены; панели не перекрывают сцену.
5. **VCB:** три состояния визуально различимы; ошибка — красным значением, рамкой и текстом; поведение ввода (Enter/Esc, ошибки `Vcb.Error*`) не изменилось.
6. **Вкладки проектов:** переключение и закрытие работают; активная вкладка выделена акцентной строкой.
7. **Welcome и диалоги:** экраны в единой теме; «Настройка панели» управляет плавающими группами; drag&drop и «сброс к исходной» из tool-palette DoD работают.
8. **Темы и локализация:** тёмная/светлая темы и RU/EN — корректны во всех новых экранах (токены, `currentColor`, resx-ключи).
9. **Адаптивность:** 1920/1440/1280/960/768 px и zoom 90–125% — без горизонтального скролла и обрезки; деградация дока/палитры работает.
10. **Смоук:** все сценарии DoD tool-palette (палитра, вылеты, настройка, жесты, урок) продолжают работать; регрессий нет.

## 6. Риски

| # | Риск | Вероятность | Влияние | Митигация |
|---|---|---|---|---|
| R1 | Tear-off drag&drop сложнее оценки (зоны докинга, z-order, HiDPI, мультимонитор) | Средняя | Среднее | Итеративная поставка: сначала плавающее окно, потом зоны; эталонные сценарии на 125% zoom |
| R2 | Плавающие группы сами по себе перекрывают сцену (вход в противоречие с no-overlay) | Средняя | Низкое | По умолчанию группы докованы; плавание — явный выбор пользователя; полупрозрачность при перетаскивании |
| R3 | Хотбокс — непривычный паттерн для новичков | Средняя | Среднее | Палитра остаётся базовым каналом; подсказки жестов в статусе; шаг урока про хотбокс |
| R4 | Радиальное меню пишется с нуля (~1–2 дня) и может «не зайти» | Низкая | Среднее | Вынести хотбокс в последнюю волну; возможность переоценить после теста на школьниках |
| R5 | Светлая «производная» тема устареет первой (хардкод цветов в старых экранах) | Средняя | Среднее | Только токены (`DynamicResource`); чек-лист экранов в DoD §5.8; запрет литералов цветов в новых стилях |
| R6 | Большой объём стилизации «за один заход» (релиз-риск) | Средняя | Среднее | Волны поставки: токены → главный экран → док → tear-off/слой C → Welcome/диалоги; смоук после каждой волны |
| R7 | Миграция JSON-раскладки (новые ключи доков/групп) ломает старые настройки | Низкая | Среднее | Версия схемы + миграция (паттерн tool-palette T8); дефолты из `ToolGroupRegistry` |

| Концепт | **Гибрид A+C + перемещаемые группы** — утверждён заказчиком; A/B/C — «в запас» (§4) |

| Носитель инструментов | Палитра сохраняется, но трансформируется: группы перемещаемы (tear-off) в любое место экрана |

| Дубли команд | Тулбар-строка упразднена (дублировала меню); команды — в меню, шапке и Ctrl+K |
| Хотбокс | Входит в состав как третий, опциональный слой; вынесен в последнюю волну поставки (риск R4) |
