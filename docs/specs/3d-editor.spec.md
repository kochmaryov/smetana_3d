## 1. Цель

Настольное приложение для 3D-моделирования «в духе SketchUp» для школьников и студентов: немного понятных инструментов, закрывающих большинство задач; концепция компонентов (по сути ООП); лёгкий вход.

Продукт равнозначно закрывает два направления:

1. **3D-печать** — точный экспорт STL/3MF/OBJ, контроль единиц измерения, проверка моделей на печатаемость (замкнутость, толщина стенок).
2. **Промышленный дизайн** — точные размеры и ввод чисел, симметрия/зеркало, массивы, оболочка, фаски, презентационные стили.

**Проблема.** SketchUp нельзя купить из России (санкции), а доступные альтернативы (FreeCAD, Blender, Fusion 360) либо сложны для школьников, либо решают только одно из двух направлений, либо тоже недоступны. Ниша: простой инструмент уровня SketchUp с локальной покупкой, офлайн-работой и встроенной готовностью к 3D-печати.

**Конкурентный контекст (по данным исследований).** SketchUp продаётся только подпиской: Pro — ~$399/год, Studio — ~$859/год; покупка из России заблокирована Trimble («unable to accept orders from Russia… due to US or EU Sanctions»); Linux-версии нет. SketchUp for Schools бесплатен для K-12, но привязан к Google/Microsoft-аккаунтам и работает только в браузере. Бесплатный FreeCAD сложен для школьников (хрупкие ограничения эскизов, разрозненные верстаки), Blender — не CAD. Свободная ниша, подтверждённая обзором: *середина между «игрушками» (Tinkercad) и инженерным CAD (FreeCAD/Fusion) — простой, офлайновый, русскоязычный инструмент с готовностью к 3D-печати для 7–11 классов и первых курсов*. Ценовой ориентир конкурентов за разовую покупку: MoI 295 $, Plasticity 175–299 $, Rhino EDU 195 €.

**Критерии успеха продукта:** школьник 14–17 лет без опыта за 15 минут строит простую деталь и экспортирует валидный STL; модель с заданными размерами печатается с точностью до 0,01 мм; покупка и активация возможны из России без VPN.

## 2. Область действия

### Входит

- Оффлайн-десктопное приложение: Windows 10/11 x64 и Linux x64 (референс — Ubuntu 22.04+)
- Мешевое моделирование: push/pull, inference-привязки, группы и компоненты
- Точность: размеры, ввод чисел, направляющие, единицы измерения (мм/см/м/дюймы)
- Инструменты промышленного дизайна: симметрия, массивы, оболочка, фаски, выдавливание по траектории
- Готовность к 3D-печати: импорт/экспорт STL/3MF/OBJ, анализ печатаемости, зона печати принтера
- Собственный формат проекта + открытые форматы обмена (STL, 3MF, OBJ, DXF, SVG, PNG/JPG/PDF)
- Русская и английская локализация, встроенные обучающие материалы
- Лицензирование: покупка, ключи, офлайн-активация, пробный период

### Не входит (non-goals, горизонт v1)

- Параметрический B-rep CAD: история операций, связи-констрейнты, допуски, редактирование STEP (кандидат на v2)
- Облачная совместная работа и обязательная учётная запись/интернет
- Поддержка записи формата SKP — юридически рискованно и не планируется; чтение SKP — только в v1.x через конвертацию SKP→OBJ (см. M8), собственный парсер SKP в ядро не встраиваем
- Архитектурная визуализация уровня Enscape, анимация, фоторендер
- Скульптинг (ZBrush-подобный), CAM для ЧПУ, инженерные расчёты (CAE)
- macOS/iPad/веб-версии на старте (macOS — кандидат v2)
- Магазин расширений на старте (API плагинов — да, маркетплейс — позже)

## 3. Пользователи и функциональные требования

### 3.1. Пользователи и сценарии

| Пользователь | Ключевые потребности |
|---|---|
| Школьник 12–17 лет | лёгкий вход, наглядность, быстрый результат для 3D-печати |
| Студент 18–25 лет | точность, инструменты промышленного дизайна, экспорт для отчётов |
| Преподаватель | воспроизводимость уроков, шаблоны, работа без интернета |

| Сценарий | Описание | Критерий |
|---|---|---|
| S1 «Первое знакомство» | построить простую деталь (стакан, подставка, корпус) и экспортировать STL | ≤ 15 минут новичком |
| S2 «Урок по чертежу» | повторить задание с точными размерами, сверить габариты | точность до 0,01 мм |
| S3 «Корпус для электроники» | вырезы, отверстия, оболочка с толщиной стенки, проверка печатаемости, разбивка на части | STL проходит проверку в слайсере |
| S4 «Концепт изделия» | обводы, фаски, симметрия, массивы, материалы, стили, экспорт изображений | презентация без внешних инструментов |
| S5 «Сборка из компонентов» | библиотека деталей, инстансы компонентов, правка мастер-компонента | правка отражается на всех инстансах |

### 3.2. UX-принципы (обязательные)

1. Мало инструментов на виду; продвинутое — в панелях (progressive disclosure).
2. Inference-привязки с визуальной обратной связью (цвета осей, значки привязок) — сердце UX.
3. Ввод чисел в строку значений (VCB) у каждого инструмента; никаких модальных диалогов.
4. Дешёвый и полный undo/redo; никаких «Вы уверены?».
5. Режим «Новичок»: подсказки к инструментам, интерактивные уроки, безопасные ошибки.
6. 100% русская локализация, тёмная/светлая темы, настраиваемые горячие клавиши.

### 3.3. Перечень модулей системы

Приоритеты: **MVP** (v1.0) → **v1.x** (ближайшие версии) → **backlog** (позже).

#### M1. Ядро сцены и 3D-вьюпорт — MVP

Мешевая модель сцены (полумногоугольники), иерархия объектов, собственный рендерер (OpenGL): орбита/панорама/зум, перспектива и ортография, стандартные виды, режимы отображения (каркас, штриховка, с текстурами, рентген), оси и сетка, секущие плоскости (*v1.x*), тени и «солнце» (*v1.x*). Бюджет производительности — см. DoD.

#### M2. Инструменты эскиза и моделирования — MVP

Рисование: Line, Freehand, Rectangle, Circle, Polygon, Arc. Редактирование: Push/Pull, Offset, Move/Copy, Rotate, Scale, Eraser, Soften/Smooth edges, Paint Bucket (цвет и материал). Точное восстановление геометрии (stickiness/склеивание граней) — ключевое поведение SketchUp.

#### M3. Inference-система привязок — MVP

Привязки к осям (красная/зелёная/синяя), концам, серединам, точкам пересечения, перпендикулярам, параллелям, тангенсам; визуальные подсказки; фильтры привязок; направляющие (guides) из линейки; ввод чисел и координат в VCB. Это главный дифференциатор удобства — реализуется вплотную до остальных модулей.

#### M4. Размеры, аннотации, точность — MVP (базово) → v1.x

Размерные линии (линейные, выровненные; угловые и радиальные — *v1.x*), текстовые метки, масштабирование модели по заданному размеру, линейка/направляющие, точный ввод координат, отображение размеров в заданных единицах. *v1.x:* «живые размеры» — правка числа в размере перестраивает геометрию (direct-моделирование с параметрикой «в духе Plasticity»; полное дерево истории — см. non-goals, кандидат v2);2D-документация: чертёжные виды с размерами и выносками, экспорт PDF/DXF (оформление по ЕСКД — востребовано в российских школах).

#### M5. Группы, компоненты, структура сцены — MVP (группы и компоненты) → v1.x (библиотеки)

Группы; компоненты: определение + инстансы, вложенность, редактирование на месте, наследование изменений мастер-компоненты, копия/прокси; теги/слои с видимостью; дерево сцены (Outliner) с поиском и переименованием; библиотека компонентов во внешних файлах (*v1.x*); сборочные Snaps — пользовательские точки привязки/ориентации в компонентах (механические стыки, «скрытый функционал» SketchUp, полезен для корпусных изделий) — *v1.x*.

#### M6. Твёрдые и точные операции — MVP (частично) → v1.x

MVP: массивы (линейный/круговой), зеркало/симметрия, Follow Me (выдавливание по траектории), простое вращение (revolve), булевы операции (объединение/разность/пересечение). v1.x: Shell (оболочка с толщиной стенки — критично для корпусов под 3D-печать), полный набор Solid Tools (trim/split/outer shell), Fillet/Chamfer по рёбрам, лофт между профилями, проверка «solid» (watertight).

#### M7. Материалы, текстуры, визуализация — MVP (цвета) → v1.x (стили)

Цвета и простые материалы, текстуры из изображений (проекции UV, масштаб/поворот), стили отображения (эскизный чертёж, технический, реалистичный), экспорт изображений PNG/JPG/PDF, секущие плоскости, тени по дате/времени, сцены (сохранённые состояния вида для презентации) (*всё — v1.x, кроме цветов*). Экспорт glTF/GLB для веб-просмотра и публикации работ — *v1.x*.

#### M8. Контур 3D-печати — MVP (экспорт/импорт) → v1.x (анализ)

Экспорт STL (binary/ASCII), 3MF, OBJ с явным контролем единиц; импорт STL/3MF/OBJ с нормализацией и валидацией; проверка печатаемости: замкнутость (watertight), самопересечения, «острые»/тонкие элементы (*v1.x* — анализ толщины стенок, автоисправление, разбиение на части); визуализация зоны печати (build volume) популярных принтеров. *v1.x:* импорт SKP через конвертацию SKP→OBJ (интеграция внешнего конвертера/SDK с проверенной лицензией) с контролем единиц и отчётом о потерях — перенос моделей пользователей из SketchUp.

#### M9. Файлы, проекты, библиотеки — MVP (формат и автосохранение) → v1.x (библиотеки)

Собственный формат проекта (сцена, компоненты, материалы, единицы, настройки вида); автосохранение и восстановление; шаблоны (единицы, стартовые сцены); локальные библиотеки материалов/комплектов компонентов, импорт/экспорт библиотек.

#### M10. Интерфейс и обучение — MVP (интерфейс) → v1.x (уроки)

Минималистичная лента инструментов, контекстная панель свойств, строка значений (VCB), undo/redo-история, горячие клавиши, вкладки проектов, палитра команд (*v1.x*), режим «Новичок» и интерактивные уроки/шаблоны-задания (*v1.x*), тёмная/светлая темы, полная локализация RU/EN.

#### M11. Расширяемость — v1.x (API) → backlog (маркетплейс)

Плагины и скрипты (C#-скриптинг, песочница), макросы, публичный API для инструментов и импорта/экспорта; маркетплейс расширений — позже. Закрывает «слабость» SketchUp (зависимость от сторонних расширений) за счёт встроенного набора операций + открытого API.

#### M12. Лицензирование и распространение — MVP (ключ и активация) → v1.x (обновления)

Покупка на сайте, лицензионные ключи, офлайн-активация (привязка к устройству), пробный период, деактивация/перенос лицензии, автообновления, российская платёжная инфраструктура. Учёт образовательных и сетевых (floating) лицензий для классов — *v1.x*; в MVP — только личные ключи.

## 4. Решения

| Область | Решение | Обоснование |
|---|---|---|
| Язык и UI | **C# (.NET 10 LTS) + Avalonia 12.x (MIT)** | Быстрая разработка соло-командой, кроссплатформа Win/Linux из коробки, зрелый tooling, безопасная лицензия; один язык для ядра, UI и плагинов. .NET 10 — текущий LTS (11.2025→11.2028); .NET 8/9 истекают 11.2026. В Avalonia есть модуль Avalonia.OpenGL; готового CAD-виджета нет — вьюпорт пишем сами (прецеденты: OpenTKAvalonia, WoWDatabaseEditor, lceda_step_downloader) |
| Рендеринг | Собственный вьюпорт на **OpenGL (core) через Silk.NET (MIT)** | Полный контроль над производительностью на слабых ПК; готовые движки (Unity/Unreal) — избыточный вес и лицензии. OpenTK не берём: SPDX-лицензия NOASSERTION. Veldrid (MIT) — запасной вариант |
| Геометрическое ядро | **Mesh-first**: полумногоугольники + CSG через **Manifold (Apache-2.0)** по его C API (`MANIFOLD_CBIND`) | Соответствует философии SketchUp (push/pull на гранях), без тяжёлого B-rep; Manifold гарантирует валидные «solid»-результаты, что критично для 3D-печати. C#-биндинг ManifoldNET — alpha (1.0.x, 2024), поэтому пишем свой тонкий слой поверх C API |
| Формат проекта | Собственный (JSON + бинарные ассеты) + открытые форматы: STL, 3MF, OBJ, DXF, SVG, PNG/JPG/PDF, glTF | Долговечность данных пользователя, независимость от вендоров, отсутствие юридических рисков (запись SKP не делаем; чтение — через конвертацию, см. M8). Реализации проверены: lib3mf (BSD-2-Clause, офиц. C/C++/C# API), IxMilia.Dxf (MIT, активен), SharpGLTF (MIT), geometry3Sharp (Boost-1.0) — всё допустимо для закрытого платного продукта |
| Плагины | C#-скриптинг (Roslyn) в песочнице | Единый язык с ядром; безопаснее и мощнее Lua/JS; без GPL-зависимостей |
| Лицензии зависимостей | Только MIT/Apache-2.0/BSD/Boost; инвентаризация лицензий (SBOM) | Платный закрытый продукт без обязательств раскрытия исходников и без роялти. Проверено: выбранный набор перmissive; исключаем AssimpNet и Occt.NET (лицензия не указана), любые GPL-компоненты (SolveSpace, Dune 3D, Blockbench) |
| Продажа и активация | Сайт + ключи + офлайн-активация; оплата — ЮKassa / CloudPayments / Робокасса / Т-Банк (все — 54-ФЗ, автоплатежи) | Работает из России без санкционных ограничений; Stripe для резидентов РФ закрыт, продажи за рубеж — через MoR-посредника (модель Plasticity/Paddle, проверить доступность для РФ). Активация: токен + node-lock + лимит активаций в год — рабочая схема проверена на Plasticity |
| Тестирование | Юнит-тесты ядра + «golden-меш» тесты экспорта + смоук на Win/Linux CI | Стабильность геометрии и экспорта — главное качество продукта для 3D-печати |

| Вариант | Идея | Плюсы | Минусы | Когда берём |
|---|---|---|---|---|
| B. C++20 + Qt6 + OpenCASCADE | «Классический CAD-стек» (как FreeCAD, Dune 3D): точное B-rep ядро | Максимальная точность геометрии, филлеты/лофт/STEP на уровне CAD-класса, производительность; прецеденты соло-CAD подтверждены (Dune 3D, SolveSpace) | Медленная разработка соло; C++ сложнее; Qt — LGPLv3 с обязательствами (динамическая линковка/релинковка) или коммерческая Qt Small Business 546 €/год; OCCT — LGPL-2.1 + exception (с уведомлением); GPL-код соло-CAD включать нельзя | Если v2 потребует настоящего параметрического B-rep |
| C. Tauri (Rust) + Three.js/WebGPU | Веб-UI + ядро на Rust (Manifold есть и в виде WASM) | Самый быстрый путь к красивому UI, шейдеры, лёгкая сборка | Память и производительность на слабых школьных ПК; мост webview↔ядро на каждую операцию; сложнее точный ввод | Если приоритет — скорость прототипа, а не производительность |
| D. Python + PySide6 + VTK | Скриптовый прототип | Скорость разработки, простые плагины | Производительность ядра, тяжёлые сборки, ложные срабатывания антивирусов, слабый UX | Только для прототипа проверки идей |
| E. Blender + свой аддон | Поверх готового 3D-пакета | Быстрый старт, мощный рендер | GPL (исходники открыты), UX ограничен дизайном Blender, «тяжёлое» для школьников | Не берём; упомянуто для полноты |

**Итог:** рекомендуется вариант **A (C#/.NET + Avalonia + Manifold)** — весь набор перmissive, закрытый платный продукт лицензионно безопасен. Резерв при нехватке геометрической точности — вариант B (нативный B-rep-модуль на OCCT с доступом через C API как отдельный процесс/библиотека): готовых кроссплатформенных .NET-привязок OCCT нет (Occt.NET — без лицензии, xBIM — Windows-only), поэтому прямой «встраиваемый» путь в C#-стек не рассматриваем.

## 5. DoD (критерии готовности v1.0)

1. **Кроссплатформенность:** приложение запускается и стабильно работает на Windows 10/11 x64 и Ubuntu 22.04+ x64; холодный старт ≤ 5 с.
2. **Лёгкий вход:** новичок (5 школьников 14–17 лет) по встроенному уроку за ≤ 15 минут строит деталь и экспортирует STL; ≥ 4 из 5 справляются без посторонней помощи.
3. **3D-печать:** экспорт STL/3MF открывается в PrusaSlicer и Cura без ошибок; эталонные модели (корпус, подставка, стакан) печатаются на FDM-принтере без доработок.
4. **Точность:** размер, заданный числом (100,00 мм), сохраняется в модели и в экспорте с погрешностью ≤ 0,01 мм.
5. **Компоненты:** изменение мастер-компоненты отражается на всех инстансах, включая вложенные (сценарий S5).
6. **Производительность:** ≥ 30 FPS на модели 500 000 треугольников на эталонной минимальной конфигурации 8 ГБ RAM / Intel UHD 620 (2018) без дискретной видеокарты; отклик push/pull ≤ 16 мс.
7. **Локализация:** 100% интерфейса на русском языке (и английском), включая ошибки и подсказки.
8. **Лицензирование:** покупка, активация и работа без VPN из России; офлайн-активация работает ≥ 30 дней без сети.
9. **Печатаемость:** проверка watertight ловит заведомо незамкнутые модели (ложных срабатываний ≤ 5% на эталонной выборке).
