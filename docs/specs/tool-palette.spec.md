## 1. Цель

Заменить текстовую ленту инструментов (сейчас 6 кнопок + раскрываемая строка на 20+ кнопок) на **панель кнопок-иконок**, сгруппированных по задачам, с возможностью **настройки состава, порядка и своих групп**. Причина: инструментов уже 24 (M2/M4/M6) и будет 40+ (M6 v1.x, M7), текстовая лента не масштабируется, а «всё и сразу» противоречит принципу progressive disclosure (§3.2 основной спеки).

**Критерии успеха:**

1. Новичок находит базовые 6 инструментов (Выбор, Линия, Прямоугольник, Push/Pull, Перемещение, Ластик) без прокрутки и настройки.
2. Любой из 24 инструментов доступен не более чем в 2 действия (клик / клик + вылет).
3. Пользователь за ≤ 1 минуты скрывает ненужные инструменты и собирает свою группу; раскладка переживает перезапуск.

## 2. Область действия

### Входит

- **Палитра инструментов слева** (92 px, две колонки кнопок 38×38) с группами-разделами: «Рисование», «Правка», «Операции», «Размеры», «Вид».
- **Вылеты (flyout)** для родственных инструментов по треугольнику в углу кнопки: «Дуга» (2 точки / 3 точки), «Зеркало» (по оси / по 2 точкам / по грани).
- **Набор иконок**: 24 монохромных глифа 24×24 (stroke, `currentColor`), подсказки «Имя · горячая клавиша»; в режиме «Новичок» — пояснение из `HintKey`.
- **Диалог «Настройка панели инструментов»**: видимость инструментов, порядок кнопок, создание/переименование/удаление своих групп, свойства кнопки, «Сбросить к исходной».
- **Сохранение раскладки** в настройках приложения (JSON, версия схемы); применение без перезапуска.
- **Адаптивность**: 1920/1440/1280/960/768 px и zoom 90–125% — свёртка в одну колонку (≤ 960 px) и в рейл с вылетами (≤ 768 px).
- Синхронизация с локализацией RU/EN, тёмной/светлой темой и каталогом горячих клавиш (`ShortcutMap`).

### Не входит (non-goals)

- Палитра команд Ctrl+K (планировалась в M10 v1.x; макет — вариант D, отдельная спека).
- Переработка VCB-строки, правой панели, меню, вьюпорта — остаются как есть.
- Пользовательские иконки (импорт SVG) — v1.x.
- Режим сенсорной/интерактивной доски (только зафиксировать риск размера кнопок).

## 4. Решения

| Область | Решение | Обоснование |
|---|---|---|
| Носитель инструментов | **Вертикальная палитра слева 92 px**, две колонки кнопок 38×38 — вариант A (утверждён 2026-10-24) | Все инструменты видны (важно для сценария S1 «15 минут»), один клик до инструмента, привычно пользователям SketchUp. Цена — 92 px ширины вьюпорта; принята осознанно |
| Группировка | Разделы с подписями в порядке частоты использования: Рисование → Правка → Операции → Размеры → Вид | Подписи групп самодокументируемы для школьников; порядок соответствует сценариям S1–S4 |
| Родственные инструменты | Вылет-меню по треугольнику в углу кнопки (Дуга ×2, Зеркало ×3) | Не раздувает палитру; все подварианты — в 2 действия |
| Иконки | Собственный набор 24 глифов 24×24 (stroke-стиль, `currentColor`), ресурсы приложения | Единый стиль, автоматическая перекраска под тему; импорт SVG — v1.x |
| Подсказки | Тултип «Имя (локализация) · жест»; в режиме «Новичок» + пояснение `HintKey` | Компенсирует отсутствие подписей у кнопок (риск R3) |
| Настройка интерфейса | Диалог «Настройка панели инструментов»: дерево «Все инструменты» ↔ «Панель» с drag&drop, «Новая группа», свойства кнопки, «Сбросить» | Покрывает T3 целиком; единая модель «группа/порядок/видимость» переиспользуема будущей лентой/палитрой команд |
| Хранение раскладки | JSON в настройках приложения (рядом с `EditorOptions`), версия схемы, дефолты из реестра инструментов | Простота, перенос между версиями через миграцию схемы; отсутствие дублей — дефолт генерируется из `Register*Tools` |
| Единый источник инструментов | `ToolGroupRegistry` поверх существующих `ToolDefinition` / `RegisterDrawingTools` / `RegisterEditingTools` / `RegisterM6Tools` / `RegisterDimensionTools` | Устраняет дублирование списков (риск R6); регистрация модулей не меняется |
| Адаптивность | ≤ 960 px — одна колонка; ≤ 768 px — палитра сворачивается в рейл с вылетами (наработка варианта C) | Покрывает DoD по 768 px и zoom 125% без горизонтального скролла |
| Горячие клавиши | Жесты — только из `ShortcutMap` (как нынешний `ToolStubViewModel.Gesture`); редактирование остаётся в панели «Горячие клавиши» | Единый источник истины, требование T5 |
| Локализация | Новые ключи (имена групп, диалог) — в `LocalizationKeys` / `Strings.resx` (+ `Strings.en.resx`) | Требование T6; общий resx пополняется точечно |

### Альтернативы «в запас»

| Вариант | Идея | Почему не взяли | Когда берём |
|---|---|---|---|
| B. Лента с группами сверху | Подписанные группы + разделители на горизонтальной ленте | Уступает по критерию «все инструменты видны»; overflow «…» на 1280 px | Если высота экрана станет ограничением (нетбуки 768 px как основная цель) |
| C. Рейл + выдвижные панели | 56 px рейл групп, панели с 📌-закреплением | Два действия до инструмента спорят с S1; сложнее состояние UI | Как эволюция при 40+ инструментах; наработка «свёртки в рейл» уже используется в этом спеке |
| D. Минимализм + Ctrl+K | Закреплённые 5–7 иконок + палитра команд | Новичок не видит набора инструментов; группировки нет | Палитра команд — v1.x (M10), как дополнение к палитре |

## 5. DoD (критерии готовности)

1. **Состав:** все 24 инструмента доступны кнопками-иконками в 5 группах; базовые 6 видны без прокрутки на 1280×800.
2. **Вылеты:** «Дуга» (2 варианта) и «Зеркало» (3 варианта) работают; выбор — в 2 действия.
3. **Настройка:** скрытие/показ, порядок (drag&drop), создание/переименование/удаление своей группы, сброс; изменения применяются без перезапуска и сохраняются между сессиями.
4. **Горячие клавиши:** все жесты `ShortcutCatalog` работают, отображаются в тултипах; правка жеста сразу видна в подсказке.
5. **Локализация и темы:** RU/EN и тёмная/светлая тема — подписи и иконки корректны (`currentColor`).
6. **Адаптивность:** 1920/1440/1280/960/768 px, zoom 90–125% — без горизонтального скролла и обрезки кнопок.
7. **Новичок:** подсказки к кнопкам и подсветка текущего шага урока работают как сейчас.
8. **Смоук:** палитра и диалог открываются, выбор инструмента из палитры/вылета активирует его (`SmokeCheck`).

## 6. Риски

| # | Риск | Вероятность | Влияние | Митигация |
|---|---|---|---|---|
| R1 | 92 px палитры заметно уменьшают вьюпорт на 1280 px | Средняя | Среднее | Компактный режим (одна колонка), свёртка в рейл ≤ 960 px; оценить на эталонных сценариях |
| R2 | Переполнение палитры по высоте при zoom 125% / 768 px | Средняя | Среднее | Свёртка групп (аккордеон), внутренний скролл палитры, режим рейла |
| R3 | Иконки без подписей неразличимы для новичков | Средняя | Высокое | Тултипы с именами, подписи групп, режим «Новичок» с пояснениями `HintKey` |
| R4 | Новые инструменты (M6 v1.x, M7) «ломают» сохранённую раскладку | Высокая | Низкая | Версионирование схемы; новые инструменты по умолчанию добавляются в конец своей группы |
| R5 | Кнопки 38×38 мелки для сенсорных/интерактивных досок в классах | Низкая | Среднее | В спеке зафиксирована настройка размера кнопок (38/44/48 px) — реализация v1.x |
| R6 | Дублирование списков инструментов (палитра / диалог / будущие панели) | Средняя | Среднее | `ToolGroupRegistry` как единый источник; реестры модулей не дублируются |
