# Обзор инструментов 3D-моделирования для обучения (2026)

## 1. Методика и карта рынка

Материал собран по официальным сайтам, документации и открытым репозиториям; всё, что не удалось проверить на первоисточниках, помечено «непроверено». Сайты autodesk.com (HTTP 403) и 3d-coat.com (DNS/TLS-недоступность) не отвечали, поэтому по Fusion 360 и 3D-Coat часть данных опирается на Википедию и помечена как непроверенная на официальном сайте.

Рынок делится на четыре группы:
1. **Параметрические CAD** (детали, сборки, чертежи): FreeCAD, Fusion 360, Onshape, SolveSpace, Dune 3D, КОМПАС-3D.
2. **NURBS/поверхностный дизайн**: Rhinoceros, MoI 3D, Plasticity.
3. **Полигональное/скульпт-моделирование**: Blender, 3D-Coat.
4. **Обучающие «конструкторы»**: Tinkercad, BlocksCAD, OpenSCAD.

## 2. Параметрические CAD

### FreeCAD
- **Назначение/аудитория**: открытый параметрический моделировщик «для реальных объектов любого размера» — механика, изделия, архитектура, BIM, CAM; позиционируется для «hobbyist, programmer, student, teacher».
- **ОС**: Windows, macOS, Linux.
- **Распространение**: полностью свободное ПО без лицензионных сборов и регистрации; точная лицензия (LGPL) — «непроверено».
- **Сильные стороны**: дерево истории с редактируемыми параметрами, эскизы с ограничениями, чертежи (STEP/IGES/STL/SVG/DXF/IFC), огромная экосистема аддонов, FEA/BIM/CAM-верстаки, мультиплатформенность. Идеален, чтобы учить «настоящему CAD» бесплатно.
- **Слабые стороны**: хрупкие ограничения эскизов (типичная боль новичков), разрозненность верстаков, нестабильность UX — прямо названа авторами Dune 3D одной из причин создания нового инструмента.
- **Порог входа**: средний–высокий.
- **Технологии**: OpenCASCADE (ядро), Coin3D (3D-сцена), Python API, Qt (UI).

**Источники:** FreeCAD — Home; FreeCAD/FreeCAD — README (GitHub).

### Autodesk Fusion (Fusion 360)
- **Назначение**: CAD + CAM + CAE + PCB, облако, совместная работа; промышленный дизайн и изготовление.
- **ОС**: Windows, macOS, веб-браузер; мобильные просмотрщики Android/iOS.
- **Распространение**: платная подписка (trialware); есть ограниченная бесплатная персональная некоммерческая версия; студенческие/образовательные лицензии Autodesk существуют, но **непроверено** (autodesk.com блокирует доступ из этой сети).
- **Сильные стороны**: единый цикл «эскиз → модель → рендер → симуляция → CAM», прямое моделирование, работа с сетками (интеграция Meshmixer/Netfabb), облачная совместная работа.
- **Слабые стороны**: привязка к подписке и облаку, изменения условий бесплатного доступа в прошлом, нестабильный доступ к файлам без интернета.
- **Порог входа**: средний.
- **Технологии**: собственное ядро Autodesk + облачные сервисы; детали языка/фреймворка — «непроверено».

**Источники:** Autodesk Fusion — Wikipedia; Autodesk Fusion — Overview (офиц., недоступен: 403).

### Onshape
- **Назначение**: облачный «professional CAD and PDM» для образования и промышленности; реальное совместное редактирование, версии, задания.
- **ОС**: любой браузер (ChromeOS/Windows/macOS/Linux/планшеты); установка не нужна, авто-обновление каждые 3 недели.
- **Распространение**: **бесплатно для студентов и преподавателей** (профессиональный функционал); Free-план для личных проектов (только публичные документы, некоммерчески); платные Standard/Professional/Enterprise; программа для стартапов.
- **Сильные стороны**: Classes & Assignments, аналитика выполнения заданий, история правок (академическая честность), бесшовная работа в группе, PDM без файлов.
- **Слабые стороны**: требует интернета, публичность документов в Free-плане, облачная модель владения данными.
- **Порог входа**: средний.
- **Технологии**: серверная геометрия (собственное ядро Parasolid — «непроверено»), веб-клиент.

**Источники:** Onshape — Education; Onshape — Plans and Pricing.

### SolveSpace
- **Назначение**: компактный свободный (GPLv3) параметрический 2D/3D CAD: детали, механизмы, DXF/SVG для резки, STL для печати.
- **ОС**: Windows, macOS, Linux (Flatpak/Snap).
- **Распространение**: бесплатно, GPLv3.
- **Сильные стороны**: отличная учебная «малая» модель: ограничения, симуляция шарнирных механизмов, экспорт STL/DXF/STEP, мгновенная обратная связь. Хорош для введения в параметрику.
- **Слабые стороны**: нет скруглений/фасок и импорта STEP (по README Dune 3D), маленькая экосистема.
- **Порог входа**: средний.
- **Технологии**: C++, собственный солвер ограничений (используется как библиотека в Dune 3D), собственное геометрическое ядро.

**Источники:** SolveSpace — Home; solvespace/solvespace — README (GitHub); dune3d/dune3d — README (GitHub).

### Dune 3D
- **Назначение**: новый свободный параметрический CAD — проектирование корпусов для 3D-печати вокруг электроники; автор противопоставляет его FreeCAD и SolveSpace.
- **ОС**: Linux, Windows.
- **Распространение**: бесплатно, открытый исходный код (GPL-3.0).
- **Сильные стороны**: ограничения в 2D **и 3D**, STEP-импорт/экспорт, скругления и фаски, «spacebar-меню» как в Horizon EDA, современный чистый код.
- **Слабые стороны**: молодой проект, мало обучающих материалов, нет macOS-сборки.
- **Порог входа**: средний (компактный UI).
- **Технологии**: C/C++ (GitHub API), Open CASCADE (ядро), солвер SolveSpace как библиотека, кодовая база из Horizon EDA.

**Источники:** Dune 3D — Home; dune3d/dune3d — README (GitHub); GitHub API (лицензия GPL-3.0).

### КОМПАС-3D (АСКОН)
- **Назначение**: российская импортонезависимая САПР для машиностроения, приборостроения, строительства; оформление КД по ЕСКД/ГОСТ.
- **ОС**: Windows 10/11 x64; нативные сборки под Alt Рабочая станция 11, RED ОС 8.0, Astra Linux 1.8 (для прочих Linux — WINE@Etersoft).
- **Распространение**: коммерческая — 287 000 ₽ постоянная лицензия или от 43 100 ₽/квартал; есть отдельная **«КОМПАС-3D Учебная версия»** для школ, колледжей и вузов; включена в единый реестр российских программ (№ 697).
- **Сильные стороны**: стандарт де-факто в российской промышленности, сильные чертежи и спецификации, отраслевые приложения, учебные материалы на русском, привязка к ФГОС-подготовке инженеров.
- **Слабые стороны**: платный вход для «домашнего» использования, экосистема заточена под российские стандарты, нет браузерной версии.
- **Порог входа**: средний (заявлено «простота освоения» — «непроверено» количественно).
- **Технологии**: российское геометрическое ядро **C3D** (C3D Labs, дочерняя компания АСКОН); остальное — «непроверено».

**Источники:** КОМПАС-3D — Описание; КОМПАС-3D Учебная версия.

## 3. NURBS-дизайн и моделирование «как в играх»

### Rhinoceros 3D (Rhino 8)
- **Назначение**: «jack-of-all-trades» NURBS-моделлер: промышленный дизайн, ювелирка, архитектура, суда, кайты; Grasshopper — визуальное программирование.
- **ОС**: Windows, macOS (версия для Linux — «непроверено»).
- **Распространение**: коммерческая — **995 €** (перпетуальная), **студенческая 195 €** (перпетуальная, коммерческое использование разрешено), 90-дневная полнофункциональная пробная версия.
- **Сильные стороны**: точные поверхности, Grasshopper + >1500 аддонов (food4Rhino), ShrinkWrap для водонепронечных сеток под 3D-печать, открытый формат 3DM (openNURBS).
- **Слабые стороны**: цена, нет истории-параметрики «по умолчанию» (Rhino 8 добавляет SolidTools/History — «непроверено»), тяжёл для школьников.
- **Порог входа**: средний–высокий.
- **Технологии**: собственное NURBS-ядро; openNURBS SDK — C++ библиотеки + .NET/Python/JS-обёртки (rhino3dm).

**Источники:** Rhino 3D — Home (цены); Rhino — The openNURBS Initiative.

### MoI 3D (Moment of Inspiration 4)
- **Назначение**: NURBS-CAD «для дизайнеров и художников», акцент на простоту и скорость; компаньон к DCC/рендер-пайплайнам.
- **ОС**: Windows и macOS (одна лицензия кросс-платформенная).
- **Распространение**: разовая покупка — **295 $** (полная версия), **100 $** (апгрейд); существовали EDU-лицензии (для старых версий — «непроверено» для v4).
- **Сильные стороны**: минимальный интерфейс, булевы операции, «best-in-industry mesh export» (n-gon), прямо заявлено «great for 3D printing».
- **Слабые стороны**: нет симуляций/CAM, малое сообщество, один разработчик (Triple Squid).
- **Порог входа**: низкий для NURBS-CAD.
- **Технологии**: собственное ядро (связь с openNURBS/Rhino-технологиями — «непроверено»).

**Источники:** MoI 3D — Home; MoI 3D — Purchase.

### Plasticity
- **Назначение**: «solid and surface modeling without subscription» — хардсёрфейс для транспорта, промдизайна, игрового арта; альтернатива истории-параметрике прямым редактированием.
- **ОС**: Windows/macOS/Linux (точный список — «непроверено»; на сайте есть упоминания Windows & Mac для xNURBS).
- **Распространение**: 30-дневный триал / план Starter (без коммерции, ограниченный экспорт); **Indie — 175 $**, **Studio — 299 $** (персональные node-locked лицензии, обновления 12 мес., без подписки).
- **Сильные стороны**: филлеты и поверхности G2 (xNURBS), водонепронечные булевы, живые размеры, прямое редактирование импортированного CAD, Blender-мост.
- **Слабые стороны**: нет дерева истории, «профессиональные» инструменты только в Studio, молодая экосистема.
- **Порог входа**: средний.
- **Технологии**: ядро **Parasolid** (Siemens) + **xNURBS**; язык/UI-фреймворк — «непроверено».

**Источники:** Plasticity — Home / Pricing.

### Blender
- **Назначение**: свободный пакет 3D-графики: полигональное моделирование, скульпт, анимация, рендер; в обучении — органические формы, персонажи, визуализация.
- **ОС**: Windows 8.1+/macOS 13+/Linux (glibc 2.28+); переносимая установка.
- **Распространение**: бесплатно, **GNU GPL v2+** (Cycles — Apache 2.0).
- **Сильные стороны**: огромная база уроков, скульпт/ремеш/текстуры, Python API и аддоны, идеален для арт-направления и «моста» к игровому пайплайну.
- **Слабые стороны**: не CAD — нет параметрики, размерной точности и чертежей; для 3D-печати деталей машин нужно вручную следить за водонепронечностью; высокий порог интерфейса.
- **Порог входа**: высокий.
- **Технологии**: C/C++/Python, OpenGL 4.3/Vulkan, GPL.

**Источники:** Blender — Requirements; Blender — License.

### 3D-Coat (3DCoat)
- **Назначение**: воксельный/полигональный скульпт, ретопология, UV, PBR-текстуры, рендер — персонажи, органика, концепты.
- **ОС**: Windows, macOS, Linux.
- **Распространение**: коммерческая (trialware по Википедии); образовательные и подписочные/перпетуальные варианты — **непроверено** (3d-coat.com недоступен из сети).
- **Сильные стороны**: воксели без «воды» (watertight-модели удобны для печати), ретопо и текстуры в одном пакете, Applink-мосты.
- **Слабые стороны**: не параметрический CAD, тяжёл для школьников, сложная лицензионная политика.
- **Порог входа**: средний–высокий.
- **Технологии**: «непроверено» (закрытый код).

**Источники:** 3DCoat — Wikipedia; 3d-coat.com (недоступен).

## 4. Обучающие и «кодовые» инструменты

### Tinkercad (Autodesk)
- **Назначение**: бесплатный браузерный «3D-конструктор» для школьников: CSG-фигуры, Codeblocks (блок-код), симуляция схем; «learn how to design and print in 3D, code, and create circuits».
- **ОС**: браузер (WebGL/JavaScript), есть офлайн-приложения для планшетов — «непроверено».
- **Распространение**: бесплатно.
- **Сильные стороны**: мгновенный старт без установки, STL-экспорт, уроки и «Classroom»-режимы, безопасная среда для детей.
- **Слабые стороны**: примитивная геометрия, нет размерной точности/сопряжений, «потолок» уже через полгода обучения.
- **Порог входа**: очень низкий.
- **Технологии**: WebGL/JavaScript (Википедия).

**Источники:** Tinkercad — Learn (meta-описание); Tinkercad — Wikipedia.

### BlocksCAD
- **Назначение**: облачный блочный редактор на языке OpenSCAD для обучения математике, алгоритмическому мышлению и печати моделей; уроки для 3–12 классов (Common Core / CSTA).
- **ОС**: браузер.
- **Распространение**: бесплатный онлайн-редактор; **BlocksCAD for Education** — подписка для школ (классы, управление аккаунтами, скачивание STL, уроки); цена — «непроверено».
- **Сильные стороны**: связка «код → геометрия → 3D-печать», уроки с методичками и решениями, курсы для учителей без опыта в CAD.
- **Слабые стороны**: ограниченная геометрия CSG, нет произвольных поверхностей, «взрослый» CAD после него осваивать всё равно надо.
- **Порог входа**: низкий.
- **Технологии**: блочный интерфейс поверх языка OpenSCAD (OpenSCAD-совместимый).

**Источники:** BlocksCAD — Home; BlocksCAD — Educators.

### OpenSCAD
- **Назначение**: «3D-компилятор»: модель описывается скриптом (CSG + экструзии 2D-контуров), параметрические детали для 3D-печати.
- **ОС**: Windows, macOS, Linux/UNIX.
- **Распространение**: бесплатно, свободное ПО (GPL — «непроверено» на сайте, но репозиторий открыт).
- **Сильные стороны**: полностью воспроизводимые параметрические модели, библиотеки, идеален для STEM-курса «математика/программирование + печать», версионирование через Git.
- **Слабые стороны**: нет интерактивного «тяни-и-отпускай», крутой синтаксис, нет скруглений на уровне «из коробки».
- **Порог входа**: низкий для программистов, высокий для художников.
- **Технологии**: C++; геометрическое ядро на базе CGAL — «непроверено»; Qt-интерфейс — «непроверено».

**Источники:** OpenSCAD — Home; openscad/openscad — README (GitHub).

## 7. Выводы: что перенять и где свободная ниша

**Интерфейсные решения, которые стоит перенять:**
1. **Лестница сложности**: Tinkercad (блоки) → BlocksCAD/OpenSCAD (код) → Onshape/FreeCAD (параметрика) → Fusion/Rhino (производство). Учебный продукт должен вести по этой лестнице внутри одной среды.
2. **Ноль установки и «вечный» автосейв с историей** (Onshape): снимает главные боли школьных кабинетов и «потерял файл».
3. **Педагогический слой**: Classes & Assignments и аналитика в Onshape, классы и уроки 3–12 с методичками в BlocksCAD — это must-have, а не «фича».
4. **Мгновенная обратная связь и «одно действие — один результат»**: MoI/Plasticity показывают, что малое число контекстных команд эффективнее лент из сотен иконок; spacebar-меню Dune 3D — хороший компромисс.
5. **Параметрика с человеческим лицом**: ограничения в 2D и 3D, живые размеры (Plasticity), устойчивые ссылки между объектами — слабое место FreeCAD, которое прямо критиковал автор Dune 3D.
6. **3D-печать как first-class сценарий**: водонепронечный экспорт (MoI, ShrinkWrap в Rhino), готовые STL/STEP, шаблоны под типовые изделия.
7. **Локализация и стандарты**: КОМПАС-3D показывает ценность ГОСТ-оформления и русскоязычных методик; для российских школ это конкурентное преимущество.

**Что решается хуже всего:**
- разрыв между «игрушкой» (Tinkercad) и инженерным CAD (FreeCAD/Fusion) — середина для 7–10 классов пуста;
- обучение параметрике: ошибки ограничений и «хрупкие» деревья истории отпугивают новичков;
- проверка печатоспособности (толщина стенок, поддержки, допуски) почти нигде не встроена в учебный контур;
- работа без интернета и на слабых ПК/Linux — облачные лидеры здесь уязвимы;
- продуктовый дизайн «от эскиза до презентации»: рендер/визуализация и точный CAD живут в разных программах.

**Свободная ниша:** свободно распространяемый (или дешёвый), русскоязычный, работающий офлайн в браузере и как десктоп-приложение параметрический CAD для 7–11 классов и первых курсов: пошаговый «режим подсказок» для ограничений, встроенный анализ печатоспособности, уроки по ФГОС с журналом учителя, безопасные аккаунты, экспорт STL/STEP и «мост» к Blender/Fusion. Ни один из рассмотренных инструментов не совмещает всё это одновременно.
