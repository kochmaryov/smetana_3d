# Зона печати принтера (задача 4.5, M8)

Визуализация build volume популярных FDM-принтеров во вьюпорте редактора:
каркас зоны, сетка пола стола, подсветка геометрии «за пределами зоны» и
выбор профиля принтера с его свойствами (габариты, сопло, высота слоя).

Замеры DoD и чек-лист ручного прогона эталонных моделей в слайсерах —
в [dod-measurements.md](./dod-measurements.md).

## Профили принтеров

Каталог: [`src/SmetaNA.Rendering/PrintVolume/PrinterProfileCatalog.cs`](../src/SmetaNA.Rendering/PrintVolume/PrinterProfileCatalog.cs).
Данные — по паспортам производителей; единицы — миллиметры.

| Профиль (Id) | Зона печати X×Y×Z, мм | Сопло, мм | Высота слоя, мм |
|---|---|---|---|
| Prusa Research i3 MK3S+ (`prusa-i3-mk3s`) | 250 × 210 × 210 | 0,4 | 0,05–0,35 |
| Creality Ender-3 (`creality-ender-3`) | 220 × 220 × 250 | 0,4 | 0,1–0,4 |
| Bambu Lab X1 Carbon (`bambu-x1c`) | 256 × 256 × 256 | 0,4 | 0,06–0,28 |
| Prusa Research XL (`prusa-xl`) | 360 × 360 × 360 | 0,4 | 0,05–0,35 |
| Creality K1 Max (`creality-k1-max`) | 300 × 300 × 300 | 0,4 | 0,05–0,3 |

Профиль описывается типом `PrinterProfile`
([`PrinterProfile.cs`](../src/SmetaNA.Rendering/PrintVolume/PrinterProfile.cs)):
идентификатор, производитель/модель, габариты зоны (`BuildVolumeMm`:
X — ширина, Y — глубина, Z — высота), диаметр сопла, диапазон высоты слоя,
примечание. Новые принтеры добавляются одной записью в каталог; валидация
конструктора не допускает нулевых/отрицательных размеров и перевёрнутого
диапазона слоёв.

**Система координат зоны:** центр стола — в начале координат XY, стол —
плоскость Z=0, высота — вдоль +Z (согласовано со сеткой пола вьюпорта).
Зона печати — параллелепипед `PrinterProfile.BuildVolumeBounds`.

## Отображение во вьюпорте

Всё построение — в новых файлах `src/SmetaNA.Rendering/PrintVolume/`:

| Файл | Назначение |
|---|---|
| `PrinterProfile.cs`, `PrinterProfileCatalog.cs` | модель профиля и встроенный каталог |
| `PrintVolumeGeometry.cs` | каркас зоны (12 рёбер), сетка пола (шаг 1/2/5 × 10ⁿ мм), выборка треугольников «за пределами зоны», `PrintVolumeFit` (превышение габаритов по осям) |
| `PrintVolumeOverlay.cs` | готовый оверлей кадра: линии + треугольники подсветки + попадание модели в зону |
| `PrintVolumeGlRenderer.cs` | GL-отрисовка оверлея (line-шейдер со смещением глубины, полупрозрачная заливка + контур для «за пределами зоны») |
| `PrintVolumeState.cs` | выбранный профиль, общий для всех вьюпортов |
| `GlViewportControl.PrintVolume.cs` | точечное подключение к `GlViewportControl` (partial-класс) |

Что видно при включённой зоне:

* **каркас зоны** — 12 рёбер параллелепипеда (голубые линии);
* **сетка пола** — линии на уровне стола (Z=0) внутри пятна стола;
* **«за пределами зоны»** — треугольники модели с вершинами вне зоны
  подсвечиваются полупрозрачным красным с контуром; геометрия внутри зоны
  не меняется.

Оверлей строится лениво: при смене профиля или модели сцены
(`PrintVolumeOverlay.Build`), отрисовка идёт после кадра сцены. При
выключенной зоне (`PrintVolumeState.Current == null`) накладных расходов нет —
это поведение вьюпорта по умолчанию.

Существующие файлы `SmetaNA.Rendering` затронуты только точечно
(объявление partial-класса, вызов отрисовки после размеров, освобождение
ресурсов в деините) — см. `GlViewportControl.cs`.

## UI: выбор профиля

Модуль `src/SmetaNA.EditorUI/PrintVolume/` (новые файлы):

* `PrintVolumePanel.axaml` / `.cs` — панель «Зона печати» в правой колонке окна:
  переключатель «Показывать зону», список профилей и свойства выбранного
  профиля (габариты зоны, сопло, диапазон высоты слоя, примечание);
* `PrintVolumeViewModel.cs` — view-модель панели (своя, DataContext окна не меняется);
* `PrinterProfileOption.cs` — элемент списка (имя модели + габариты);
* `PrintVolumeStrings.cs` — строки модуля RU/EN (общие resx не трогаются,
  паттерн `DrawingToolStrings`);
* `RegisterPrintVolume.cs` — API модуля для координатора: `Profiles`,
  `CreateViewModel()`, `Apply(profile)` / `Clear()`.

Выбранный профиль публикуется через `PrintVolumeState.Current`; GL-вьюпорты
читают его каждый кадр, поэтому вкладки проектов и новые вьюпорты подхватывают
выбор без дополнительных подключений. Точечное подключение в существующих
файлах EditorUI — только элемент `<printvolume:PrintVolumePanel />` в
`MainWindow.axaml` (2 строки с xmlns).

## Как пользоваться

1. Откройте панель «Зона печати» в правой колонке главного окна.
2. Выберите принтер в списке — габариты/сопло/слой показываются под списком.
3. Включите «Показывать зону» — во вьюпорте появятся каркас и сетка стола.
4. Постройте/загрузите модель: геометрия за пределами зоны подсветится красным.
   Если модель не помещается, `PrintVolumeFit` фиксирует превышение по осям
   (используется в тестах; вывод в UI — задел).

Зона печати влияет только на отображение: экспорт STL/OBJ/3MF выполняется в
миллиметрах независимо от выбранного профиля (единицы — ответственность
слайсера).
